# SPECTATE CNC

## Installation

1. Clone the repo:
   ```bash
   git clone <repo-url>
   cd <repo-directory>
   ```

2. Build the CNC:
   ```bash
   cd cnc
   go build -o spectate-cnc
   ```

3. Run:
   ```bash
   ./spectate-cnc
   ```
